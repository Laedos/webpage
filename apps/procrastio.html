procrast.io

A JavaFX desktop focus timer and website blocker, minimizing to the system tray, with a sync backend and an Android companion app.

Kotlin JavaFX Android

Overview

procrast.io is a Kotlin + JavaFX desktop app for staying focused: a work/break focus-session timer and a hosts-file website blocker, minimizing to the system tray and running in the background. A Ktor sync backend and an Android companion app keep focus sessions and blocklists in sync across devices, with a freemium Pro tier for multi-device sync.

Key features

  • Focus-session timer with work/break phases
  • Website blocking via the system hosts file
  • System tray integration — minimizes instead of closing, with a Show/Close menu
  • Cross-device sync (desktop + Android) via a Ktor backend, free tier plus a Pro sync tier

Built with

Kotlin, JavaFX, ControlsFX, Ikonli, Maven, Ktor (sync backend), Android/Compose (mobile companion).
