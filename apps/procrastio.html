procrast.io

An early-stage JavaFX desktop app for staying focused — currently a system-tray-capable scaffold, with the real feature set still to come.

Kotlin JavaFX

Overview

procrast.io is a Kotlin + JavaFX desktop app that minimizes to the system tray and stays running in the background. The name points at a focus/anti-procrastination tool, but the project is still at the scaffolding stage — no tracking, timing, or blocking features are built yet.

Key features

  • System tray integration — minimizes instead of closing, with a Show/Close menu
  • JavaFX window shell ready for a real UI to be built on top

Built with

Kotlin, JavaFX, ControlsFX, Ikonli, Maven.
