RotaHub

A modular rotation platform for dev teams: one account, one set of teams, and pluggable rotation modules — on-call paging and pair-programming scheduling — that a team can turn on independently.

Kotlin Ktor React React Native TypeScript

Overview

RotaHub replaces two earlier single-purpose apps — an on-call scheduler and a pair-programming rotation manager — with one platform sharing a single account, team, and billing core. Each team enables the rotation modules it actually needs, instead of running two near-identical apps side by side. It ships as a web app and a native mobile app sharing one backend and one typed API client.

Key features

  • On-Call module: round-robin and least-recently-on-call rotation algorithms, shift overrides with an audit trail, push notifications with escalation on missed acknowledgement
  • Pairing module: least-recently-paired and skill-based algorithms, fixed pairs, member skill/seniority profiles, pairing-coverage view for stale pairs/skills
  • Recurring schedule automation for both modules, with optional auto-publish
  • A unified "what's on my plate" dashboard federating upcoming shifts and sessions across every enabled module
  • In-app and push notifications, with per-type preferences
  • Light/dark theme, on both web and mobile
  • Full mobile parity: team management, on-call acknowledgement, and pairing roster/schedule/session administration, not just a read-only view

Built with

Backend: Kotlin, Ktor, Koin, Exposed, Flyway, SQLite/PostgreSQL. Web: React, TypeScript, Vite. Mobile: React Native (Expo).
