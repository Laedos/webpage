HomelyEasy

Simple home management for shared households — tasks, shopping, and bills, kept in sync across everyone in the home.

Android Kotlin Jetpack Compose Spring Boot

Overview

HomelyEasy is a Kotlin + Jetpack Compose Android client backed by a Spring Boot API, built for households to coordinate day-to-day life together — chores, shopping lists, and bills — with accounts and home invites so everyone stays on the same page.

Key features

  • Shared households via deep-link invites
  • Task, shopping, and bills feature modules
  • Account system with email verification and password reset
  • Debug/release build separation with a configurable API endpoint

Built with

Client: Kotlin, Jetpack Compose, Retrofit. Backend: Kotlin, Spring Boot.
