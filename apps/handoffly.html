Handoffly

One place for the rotations and routines a dev team runs every week: on-call, pairing, code review, standups and more.

Kotlin Ktor React React Native

Overview

Handoffly gives a development team one home for the jobs that usually live in spreadsheets and chat threads: who’s on call, who pairs with whom, who reviews the next pull request, and who runs standup.

Teams switch on only the modules they need, and everyone sees what’s on their plate across all of them, on the web or in the mobile app.

Key features

  • On-call rotations with shift swaps, push notifications, and escalation when a page isn’t acknowledged
  • Pair-programming schedules that rotate partners and balance skills across the team
  • Code review rotation, with an optional GitHub integration that assigns the next reviewer when a pull request opens
  • Standup facilitator rotation
  • Shared time off: mark yourself away once, and every rotation skips you
  • An incident tracker with action items, a team wiki with page history, and a Kanban board
  • A “what’s on my plate” dashboard across every module, with push and Slack notifications
  • A full mobile app, not a read-only companion, with light and dark themes
