Handoffly

A modular dev-team platform: one account, one set of teams, and pluggable modules — on-call paging, pair-programming scheduling, code review rotation, standup rotation, incident tracking, a wiki, a Kanban board, and Slack notifications — that a team can turn on independently.

Kotlin Ktor React React Native TypeScript

Overview

Handoffly replaces two earlier single-purpose apps — an on-call scheduler and a pair-programming rotation manager — with one platform sharing a single account, team, and billing core. Each team enables the modules it actually needs — On-Call, Pairing, Code Review Rotation, Standup rotation, Incident Tracker, a Wiki, Slack notifications, and a free Kanban board — instead of running near-identical apps side by side. It ships as a web app and a native mobile app sharing one backend and one typed API client.

Key features

  • On-Call module: round-robin and least-recently-on-call rotation algorithms, shift overrides with an audit trail, push notifications with escalation on missed acknowledgement
  • Pairing module: least-recently-paired and skill-based algorithms, fixed pairs, member skill/seniority profiles, pairing-coverage view for stale pairs/skills
  • Standup module: calendar-generated weekday facilitator rotation, with manual per-day reassignment and optional auto-generation
  • Recurring schedule automation across the rotation modules, with optional auto-publish
  • Code Review Rotation module: round-robin/least-recently-reviewed reviewer suggestion, an opt-in GitHub webhook add-on that auto-suggests and requests the next reviewer when a PR opens
  • Incident Tracker module: log incidents with severity/status/assignee and an action-items checklist, with an optional on-call schedule reference
  • Wiki module: per-team markdown pages with full, restorable edit history
  • Slack notification integration: posts team invites, published schedules, and recurrence failures to a team's Slack channel
  • Kanban module: a free, always-on board per team with drag-and-drop reordering on web
  • A unified "what's on my plate" dashboard federating upcoming shifts, sessions, cards, reviews, incidents, and standups across every enabled module
  • In-app and push notifications, with per-type preferences
  • Light/dark theme, on both web and mobile
  • Full mobile parity across every module: team management, on-call acknowledgement, pairing roster/schedule/session administration, and more, not just a read-only view

Built with

Backend: Kotlin, Ktor, Koin, Exposed, Flyway, SQLite/PostgreSQL. Web: React, TypeScript, Vite. Mobile: React Native (Expo).
