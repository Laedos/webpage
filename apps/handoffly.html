Handoffly

Everything a software team runs around its code, in one place: on-call, code review, standups and retros, incidents, a Kanban board and a wiki.

Kotlin Ktor React React Native

Screenshots

Overview

Handoffly gives a development team one home for the work that happens around the code and usually lives in spreadsheets and chat threads: who’s on call and what they handed over, who reviews the next pull request, who runs standup, what went wrong last week and what the team learned from it.

Teams switch on only the modules they need, and everyone sees what’s on their plate across all of them, on the web or in the mobile app.

Key features

  • On-call rotations with shift swaps, escalation when a page isn’t acknowledged, and handoff notes between shifts
  • Code review assignment, with an optional GitHub integration that picks the next reviewer when a pull request opens
  • Pair-programming schedules that rotate partners and balance skills across the team
  • Standup facilitator rotation and retrospective boards with votes and action items
  • An incident tracker with action items and blameless postmortems
  • A Kanban board, a team wiki with page history, and a directory of who knows what
  • Shared time off that every rotation respects, plus Slack notifications and a calendar feed
  • A “what’s on my plate” view across every module, on the web and in a full mobile app
