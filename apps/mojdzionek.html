Mój Dzionek

A preschool’s day in parents’ pockets: everyday contact between the preschool and families in one app, with a web panel for the director. Made for Polish preschools and the families they serve.

React Native Expo Kotlin Ktor

Visit Mój Dzionek

Overview

Mój Dzionek (Polish for “my little day”) connects a preschool with the families it looks after. Parents follow their child’s day on their phones, teachers share it without extra paperwork, and the director runs the preschool from a web panel. It is in a pilot with its first preschool; parents never pay.

Screenshots

Key features

  • The child’s day on the parent’s phone
  • Contact between the preschool and families in one place, instead of notes on the door
  • Everyday preschool matters handled in the app
  • Quick to use for teachers during a busy day
  • A web panel for the director
  • Privacy first: everyone sees only what concerns them
  • For parents in Polish, Ukrainian or English

Built with

Mobile app
React Native (Expo), TypeScript, React Query
Web app
React, Vite, TypeScript (the director’s panel)
Server
Kotlin, Ktor, Koin, Exposed, Flyway, PostgreSQL
Architecture
Hexagonal (ports and adapters), push notifications through Expo
