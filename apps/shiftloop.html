ShiftLoop

An on-call rotation scheduler for dev teams: configure a rotation, generate the roster, see who's on call right now, and cover a shift when someone's out.

Kotlin Ktor React React Native TypeScript

Overview

ShiftLoop generates fair on-call rotations for engineering teams using a pluggable algorithm — round-robin or least-recently-on-call — and tracks the resulting schedule. It ships as a web app and a native mobile companion sharing one backend and one typed API client.

Key features

  • Round-robin and least-recently-on-call rotation algorithms, generated over any date range
  • Team roles and membership management, with invite-by-email
  • Daily/weekly rotations with configurable handoff time and timezone
  • Shift overrides — cover a teammate's on-call slot with a logged audit trail
  • Dashboard: who's on call now per team, plus your own upcoming shifts
  • Mobile companion app for checking who's on call on the go

Built with

Backend: Kotlin, Ktor, Koin, Exposed, Flyway, SQLite/PostgreSQL. Web: React, TypeScript, Vite. Mobile: React Native (Expo).
