HavenEasy

One shared app for running a household: tasks, shopping, bills and chores, in sync for everyone at home.

Android Kotlin Jetpack Compose Ktor

Screenshots

Overview

HavenEasy gives everyone in a home the same up-to-date picture: who’s doing which chore, what’s on the shopping list, and which bills are due. Invite housemates or family with a link, and a change made on one phone shows up on everyone’s.

It works offline too: edits are kept on the device and synced when you’re back online.

Key features

  • Shared homes: invite people with a link, and everyone sees the same lists
  • Tasks, chores and a cleaning rota, so housework gets shared out
  • Shopping lists and a home inventory
  • Bills and household documents in one place
  • A maintenance log and a shared calendar
  • Works offline: changes are saved on the device and synced when back online
  • Accounts with email verification and password reset

Built with

Android app
Kotlin, Jetpack Compose, Hilt, Room, Retrofit, WorkManager
Server
Kotlin, Ktor, Exposed, PostgreSQL
Architecture
Offline-first, with an outbox queue that syncs changes in the background
