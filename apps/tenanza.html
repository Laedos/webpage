Tenanza

One shared place for landlords and tenants to manage leases, rent, documents, and maintenance — Android app and web app, backed by the same API.

Android Kotlin Jetpack Compose Next.js Spring Boot

Overview

Tenanza is a property-management app for landlords and tenants, built as a Kotlin + Jetpack Compose Android client and a Next.js web client, both backed by the same Spring Boot API. Lease onboarding runs on invite links rather than requiring a tenant to already have an account, and every core workflow — rent, documents, maintenance — is shared between both sides of the lease instead of siloed to one app or the other.

Key features

  • Invite-based lease onboarding, no account required to receive an invite
  • Monthly billing statements with itemized line items
  • Document vault for leases, IDs, receipts, and property files
  • Maintenance requests, per-unit meter readings, move-in/move-out handover records with PDF export
  • Web client localized in English, Polish, German, and Ukrainian

Built with

Android: Kotlin, Jetpack Compose, Retrofit. Web: Next.js, TypeScript. Backend: Kotlin, Spring Boot.
