PairProgrammer

A pair-programming rotation manager: teams invite members, build skill/seniority profiles, log sessions, and generate rotation schedules automatically.

Kotlin Ktor React React Native TypeScript

Overview

PairProgrammer generates fair pairing rotations for engineering teams using a pluggable algorithm — least-recently-paired or skill-based — and tracks the resulting history. It ships as a web app and a native mobile app sharing one backend and one typed API client.

Key features

  • Least-recently-paired and skill-based pairing algorithms, with fixed pairs and unavailability support
  • Team roles, member profiles (skills, seniority), and pairing history with CSV export
  • Recurring schedule automation and a pairing-coverage view for stale pairs/skills
  • Dashboard with upcoming sessions and pairing analytics
  • In-app and push notifications, light/dark theme, on both web and mobile
  • Production-ready Docker Compose stack with automatic HTTPS

Built with

Backend: Kotlin, Ktor, Koin, Exposed, Flyway, SQLite/PostgreSQL. Web: React, TypeScript, Vite. Mobile: React Native (Expo).
